# Profile context

`README.md` defines the content, layout, and project metadata. This guide covers maintenance only. Audience: engineers, recruiters, curious builders, nobody.

- **Voice:** First-person, clear, credible, curious, occasionally dry. No hype or filler.
- **Form:** Keep the Python-like narrative, sections, disclosures, and GitHub-friendly layout. Do not standardize atypical syntax, comments, wording, spacing, or trailing material.
- **Projects:** Balance cloud/DevOps work with AI exploration. Distinguish ideas, implemented behavior, technical readiness, and value; verify links, claims, and attribution. Respect private boundaries.
- **Updates:** Edit only what's requested. `.meta/scripts/project_metadata.py` provides public release/activity facts; `assets/README.md` owns credits. Review the diff and GitHub rendering, and honor commit/push boundaries.

Current user instructions override this guide.
